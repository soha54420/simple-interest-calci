# Simple Interest Calculator

This project explains how to calculate simple interest using the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Example

Suppose:
- Principal = 1000
- Rate = 5%
- Time = 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100

**Simple Interest = 100**

Total Amount = Principal + Simple Interest

**Total Amount = 1100**

## Features

- Simple explanation of the simple interest formula.
- Clear description of the required inputs.
- Step-by-step calculation example.
- Suitable for beginners learning basic financial mathematics.

## Usage

Enter the principal amount, annual interest rate, and time period into the formula to calculate simple interest.
